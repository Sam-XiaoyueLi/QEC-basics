# Archive

Notebooks here are not part of the active numbered learning sequence (see the root [README.md](../README.md) for the current roadmap). They are kept for reference only and are not maintained.

- `04_syndrome_detection_circuits.ipynb` and `05_noisy_repetition_code_decoder.ipynb` were built against an earlier roadmap that continued directly from the 3-bit repetition code to ancilla circuits and noisy decoding. The roadmap was restructured to insert classical linear codes and the stabilizer/CSS/Steane trilogy first; their topics (ancilla syndrome extraction, noisy decoding) now belong later in the sequence, applied to the Steane and surface codes instead of the repetition code.
