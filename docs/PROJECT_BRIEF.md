# Project Brief

## Purpose and audience

QEC Basics is a beginner-friendly, hands-on learning repository for quantum error correction. Readers should be comfortable with basic Python but need not know QEC. Material must make sense from the README alone.

## Curation approach

Develop each notebook on a topic branch from `main`, execute runnable examples, and review the explanations together. Publish completed material to `main`.

The collection begins with the Shor-code notebook. Decide later topics as material is selected; the historical archive roadmaps are references rather than the current curriculum.

## Authoring standard

- Explain the problem before introducing notation or code.
- State prerequisites, learning objectives, required reading, and expected outcomes.
- Define terms and measurement conventions at first use.
- Use small runnable examples, inline predictions, and exercises.
- Preserve learner notes, outputs, and completed exercises.
- Keep the README and learning path aligned with reviewed material.
