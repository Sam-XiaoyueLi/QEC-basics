# QEC repository workflow

Use [the QEC knowledge-base skill](skills/qec-knowledge-base/SKILL.md) when creating or updating knowledge-base Markdown topic pages, when checking connections after notebook additions or updates, and during substantive QEC topic discussions.

Topic pages go in `qec_knowledge_base/`. Basic tutorial PDFs are in `qec_basic_notes/`. Follow the skill's page structure, related-topic maintenance, and README index workflow. Discussion alone does not require creating a topic page. Update both the repository README and the knowledge-base index when adding a topic page.
